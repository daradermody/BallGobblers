# Dev notes

## Publishing on Google Play

1. Export a build from Unity by navigating to _File > Build Profiles_ and clicking _Export_
2. Open the exported folder in Android Studio
Update versions...
3. In Android Studio, navigate to _Build > Generate Signed App Bundle or APK..._ and following all the prompts
4. In Google Play Console, upload the created file into any track (e.g. internal testing)
